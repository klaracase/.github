# Contributing

Issues and pull requests are welcome in every Klaracase repository.

- The shared conformance pack is the contract for all SDKs. A change to SDK behavior must keep the conformance cases green. Do not edit the cases in one SDK alone.
- Every behavior change needs a test. No test may touch the network.
- Never paste a real API token into an issue, a pull request or a log. Use `klc_your_token_here`.
- Keep commits small and use semantic commit messages.
- Questions about your account or billing go to support@klaracase.de, not to the issue tracker.
